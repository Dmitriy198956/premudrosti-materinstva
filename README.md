# Премудрости материнства

Материалы проекта Елены Шулениной (Челябинск) — консультанта по грудному вскармливанию
и специалиста по новорождённым.

## 🌿 Сайт для клиентов

Главная страница репозитория — публичный сайт для мам.

| Файл | Назначение |
|---|---|
| `index.html` | одностраничный сайт: услуги и цены, мини-курс, живые встречи, обо мне, FAQ, контакты |
| `style.css` | оформление сайта |
| `script.js` | мобильное меню, анимации появления, аккордеон FAQ |
| `assets/` | иллюстрации (акварель) и фоны |

Сайт статический — никакой сборки не нужно. Локальный просмотр:

```bash
python3 -m http.server 3000
# затем откройте http://localhost:3000
```

Публикация: подойдёт любой статический хостинг (GitHub Pages, Netlify, Vercel, обычный хостинг по FTP).

### Что нужно заменить перед публикацией
- ссылки `https://vk.me/ok_gv` и `https://vk.com/ok_gv` — если поменяются;
- ссылку на Telegram-чат в блоке «Связаться» (сейчас заглушка `https://t.me/`);
- блок «Отзывы мам»: в `index.html` есть закомментированный шаблон карточки отзыва —
  скопируйте его и вставьте реальные отзывы (с разрешения мам);
- при желании — заменить акварельные иллюстрации на живые фото со встреч.
